# Check-Di — Devnet Proof

Status: **not implemented yet**.

Điền tài liệu này sau khi Anchor program được khởi tạo và deploy.

## Required proof

- Program ID
- Deploy signature
- Devnet cluster
- Issuer wallet/public key dùng cho demo
- Issue transaction signature + Explorer link
- Revoke transaction signature + Explorer link
- Supersede transaction signature + Explorer link nếu có
- Attestation account/PDA address
- Schema/program version
- Test command/result

Không ghi transaction giả hoặc placeholder như thể đã deploy thành công.
